# Scratch Experiment Repository

This repository is set up for various experiments and testing.

## 🚀 Live Demo

## Experiments

### Mobile Development POC
A proof of concept demonstrating that web development and deployment is possible entirely from a mobile device using Claude Code.

- **Tech**: Static HTML + GitHub Pages
- **File**: `index.html`
- **Status**: Deployed

## Structure

- `index.html` - Hello World landing page
- `experiments/` - Directory for individual experiments
- `scripts/` - Utility scripts
- `notes/` - Documentation and notes

## Deployment

This repo auto-deploys to GitHub Pages. To enable:

1. Go to repo Settings > Pages
2. Set Source to "Deploy from a branch"
3. Select branch: `claude/setup-repo-experiment-011CUsNohe7bccfSzpxRS5B5`
4. Set folder to `/ (root)`
5. Save

Changes pushed to the branch will auto-deploy in ~1-2 minutes.

## Getting Started

Each experiment should be in its own subdirectory under `experiments/` with its own README explaining the purpose and setup.
