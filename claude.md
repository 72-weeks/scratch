# Claude Project Guidelines

## Design Principles

### Framework
- **Always use Tailwind CSS 4** for styling

### Visual Design Rules
- **No emojis** unless explicitly requested
- **No gradients** unless explicitly requested
- Focus on clean, professional aesthetics

### Core Design Principles
Elevate every design to best-in-class by focusing on:

1. **Legibility** - Text must be easy to read with proper contrast and sizing
2. **Hierarchy** - Clear visual structure that guides the user's attention
3. **Meaningful Color Usage** - Colors should serve a purpose and enhance usability
4. **Simplicity** - Remove unnecessary elements, keep interfaces clean and focused
